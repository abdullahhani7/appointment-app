# Doctor Appointment Booking System

A comprehensive web application for booking doctor appointments, allowing patients to search for doctors by specialty, view their details, and book appointments easily with full authentication.

## Overview

This system simplifies scheduling medical appointments. Patients can browse doctors by categories (e.g., Neurology, Ophthalmology), book appointments at preferred times, and manage their bookings efficiently. All data is managed via **Supabase** for seamless backend operations.

## Key Features

- **Full Authentication:** Secure login/logout and protected routes powered by Kinde Auth.  
- **Doctor Dashboard & Search:** Browse and filter doctors by specialties and view detailed profiles.  
- **Booking System:** Select date and time and book appointments with a single click.  
- **Appointment Management:** Users can view upcoming and past bookings in a personal dashboard.  
- **Dynamic Database:** Powered by Supabase for managing doctors, specialties, and appointments efficiently.  
- **Smooth UX:** Skeleton loaders and UI enhancements for a seamless user experience.  
- **Responsive Design:** Fully responsive interface compatible with all devices using Tailwind CSS.

## Tech Stack

- **Frontend:** React.js & Next.js (App Router)  
- **Styling:** Tailwind CSS  
- **Backend / Database:** Supabase (PostgreSQL)  
- **Authentication:** Kinde Auth  
- **Icons:** Lucide React
